# ADR-027: R2 Source/Citation Hard-Cut

## Status

Accepted

## Context

Prior to this change, Source and Citation facts were persisted by the Python
`SourceStore` (`core/sources.py`) to a JSON file
(`<workspace>/.delta/sources.json`), with an optional
`source_citation_delegate.py` providing a Rust final verdict when
`DELTA_RUST_AUTHORITY=source_citation` was set. This created a dual-authority
window where:

- Python performed file I/O, fingerprint computation, and range validation
- Rust provided an optional final verdict via the delegate
- A selector (`DELTA_RUST_AUTHORITY=source_citation`) controlled the switch

This architecture violated the R2 principle of **one domain, one Authority**.

## Decision

**Rust `delta_core` is the sole Source/Citation trusted authority.**

Python performs only:
- File I/O and content hashing (extraction)
- Candidate range construction from `CitationRange` dataclasses

Rust owns all trusted facts:
- Source identity, revision, and fingerprint facts
- Citation identity and source relations
- Range validation and normalization
- Stale detection and status transitions
- All persistence in the run-event ledger (`run_events.db`)

No Python fallback, dual-write, shadow production path, or migration delegate
remains. The `source_citation_delegate.py` is deleted.

## Authority Before

```
Python SourceStore (JSON persistence)
    ↓ optional delegate
Rust citation.validate / citation.canonicalize (shadow)
```

## Authority After

```
Python facade (extraction only)
    ↓ DeltaCoreClient
Rust SourceCitationWriter / SourceCitationReader (ledger persistence)
```

## Python Responsibilities

- Read file bytes, compute sha256, stat for mtime/size
- Construct candidate `CitationRange` dicts from `CitationRange` dataclasses
- Call `default_client().command()` with `source.register`, `source.get`,
  `source.list`, `source.latest`, `source.refresh`, `citation.mark`,
  `citation.validate`, `citation.list`

## Rust Responsibilities

- `SourceCitationWriter` appends `source.registered`, `citation.marked` events
  to the run-event ledger via `LedgerWriter`
- `SourceCitationReader` replays events to reconstruct `SourceRecord` state
- `validate_source_citation` derives final verdict from reconstructed state
- `validate_citation` / `validate_all` canonicalize and validate ranges
- All persistence in `run_events.db` (reusing existing ledger architecture)

## Source Identity

- Generated by Rust (UUID v4) on first registration
- Re-registration of byte-identical content refreshes the same source_id
- New fingerprint for same location → old ref marked "changed", new ref created

## Revision / Fingerprint Semantics

- `source.registered` event carries full SourceRef snapshot
- Re-registration of same fingerprint → refresh `checked_at`, `mtime_ns`, `size_bytes`
- Different fingerprint → old ref gets `status="changed"`, new ref created
- Freshness checks send observations to Rust; Rust decides verdict

## Citation Identity

- `citation.marked` event links `source_id`, `run_id`, canonicalized ranges
- Multiple citations per (source, run) accumulate (one per `mark_cited` call)
- Ranges validated and canonicalized by Rust before persistence

## Stale Detection

- Python computes observations (current fingerprint, mtime, size)
- Rust compares to recorded fingerprint, emits `source.registered` with updated status
- `source.refresh` persists refreshed mtime/size even for "current" sources

## Failure Behavior

All Source/Citation operations are **fail-closed**:

- `DeltaCoreError` raised if `delta_core` unavailable, protocol mismatch,
  malformed response, or validation failure
- No Python fallback verdict
- File-level errors (missing path, stat OSError, hash OSError) return `None`
  or `incomplete=True` — not Authority failures
- Rollback only via Git revert / release rollback

## Deleted Legacy Paths

- `core/source_citation_delegate.py` (migration delegate)
- `source_citation` selector from `RUST_WRITE_DOMAINS`
- `is_rust_authority("source_citation")` production calls
- Python final citation verdict, stale verdict, direct ledger writes
- `DELTA_RUST_AUTHORITY` no longer controls Source/Citation
- Python dual-write, dual-verdict, shadow production path

## Compatibility

- `SourceRef`, `CitationRange`, `to_range_dict`, `normalize_cited_ranges`,
  `to_dto` dataclasses retained for candidate construction and UI contracts
- `SourceStore` public API preserved (method signatures unchanged)
- `register_artifact` / `register_run_artifacts` signatures unchanged
- Legacy `sources.json` data not auto-migrated (re-register on next capture)
- Rollback via Git revert / release rollback only

## Non-Goals

- Validation Hard-Cut (#152)
- Approval migration
- Policy migration
- Checkpoint migration
- PDF/Office/OCR parser rewrite
- New Source providers
