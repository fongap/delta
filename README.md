# Delta

Delta 是一款本地优先的个人 AI 工作助手，基于   <a href="https://github.com/andrewyng/openworker" target="_blank" rel="noopener noreferrer" style="color: inherit; text-decoration: none;">OpenWorker</a>  深度定制，专注于中文体验、本地运行与个人工作流。

## 项目简介

Delta 帮助用户理解任务、组织步骤、调用本地资源并完成实际操作。模型由用户自行配置，不绑定特定服务商。

## 主要能力

- **理解任务**：识别用户意图并拆解执行步骤
- **规划执行**：根据任务组织和推进工作流程
- **调用资源**：读写本地文件、调用工具
- **执行操作**：完成任务所需的具体动作
- **关键审批**：重要操作执行前请求用户确认

## 发展方向

Delta 将继续坚持本地优先，逐步完善：

- **任务检查**：支持长任务中断与恢复
- **来源引用**：让结果能够追溯到原始资料
- **执行记录**：便于检查、复盘与审计
- **受控学习**：在明确边界内积累和改进经验

目标是让较长任务能够恢复、复盘和持续改进，而不局限于一次性对话。
